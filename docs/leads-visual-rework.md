# Leads Visual Rework

Figma reference: https://www.figma.com/design/Ii1vfJIZavsKz9B97nDpxn

Scope of this branch is visual-only for the Leads workflow. Existing ViewModel state, callbacks, persistence, Hotbox behavior, lead status transitions, call handling, filters and dialogs remain unchanged.

Visual focus:
- dark navy glass surfaces
- cyan / teal / amber / violet status accents
- stronger focus glow for the next action and primary call CTA
- active workflow step glow
- glow only while a lead card is actively expanded
- improved borders, gradients and hierarchy without adding new business behavior
