# 📝 KI-Agent: Beispiele & Use Cases

Hier sind verschiedene Beispiele, wie du das CRM-System von STROMRUF per Sprache bedienen kannst.

## Einfache Anweisungen

### Kontakt-Management
```
"Erstelle einen neuen Kontakt für Max Müller mit Telefon 0491234567"
"Erstelle einen Kontakt namens Schmidt, Firma ABC GmbH, Email schmidt@abc.de, Telefon 0341234567"
"Zeige mir alle Kontakte"
"Zeige mir Kontakte von Firma ABC"
"Aktualisiere Max Müller: setze die Email auf max@example.com"
"Lösche den Kontakt Hans Schmidt"
"Zeige mir alle Hot-Box Kontakte"
```

### Wiedervorlagen & Reminders
```
"Erstelle eine Wiedervorlage für Max Müller in 3 Tagen"
"Erstelle eine Wiedervorlage für 0491234567 in 1 Woche"
"Zeige mir alle ausstehenden Wiedervorlagen"
"Zeige mir Wiedervorlagen für diese Woche"
"Markiere die Wiedervorlage für Max Müller als erledigt"
```

### Anrufe & Anrufverlauf
```
"Protokolliere einen Anruf für 0491234567"
"Protokolliere Anruf für Max Müller mit Outcome 'nicht erreicht' und Dauer 120 Sekunden"
"Zeige mir die letzten 10 Anrufe"
```

### Analytik & Reports
```
"Gib mir eine Zusammenfassung: Kontakte, Wiedervorlagen, Anrufe diese Woche"
"Zeige Statistiken für diese Woche"
```
